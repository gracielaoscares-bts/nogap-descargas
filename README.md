# Descargas de NOGAP

Instaladores de **NOGAP para computadora**: la app que quita los silencios de
tus videos, mejora tu voz y suma música, subtítulos y texto a voz.

👉 Descargala desde **https://nogap-app.com** o desde la sección
[Releases](https://github.com/gracielaoscares-bts/nogap-descargas/releases/latest).

- **Windows:** `NOGAP-Setup.exe` (Windows 10 u 11, 64 bits).
- **Mac:** `NOGAP-mac-arm64.dmg` (Mac con chip Apple M1 o más nuevo).
- **Celular:** NOGAP para Android está en Google Play.

Este repositorio solo guarda los instaladores; no contiene el código de la app.
